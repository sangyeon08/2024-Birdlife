# 2024-Birdlife

2024 MSG 1학년 프로젝트

## 프로젝트 소개

이 프로젝트는 간단한 독서록(독후감) 웹 서비스입니다.  
사용자는 회원가입 및 로그인을 통해 본인의 독서 기록을 남기고, 기존의 독서록 목록도 확인할 수 있습니다.

## 주요 기능

- 회원가입 및 로그인
- 나의 독서록 작성 및 저장
- 등록된 독서록 목록 확인

## 폴더 및 파일 구조

```
├── HomePage.html      # 메인 홈 페이지
├── HomeCSS.css        # 메인 페이지 스타일
├── MyBook.html        # 나의 독서록 목록 페이지
├── MyBook.css         # 독서록 목록 스타일
├── Write.html         # 독서록 작성 페이지
├── Write.css          # 독서록 작성 스타일
├── login.html         # 로그인 페이지
├── logincss.css       # 로그인 페이지 스타일
├── signup.html        # 회원가입 페이지
├── signup.css         # 회원가입 스타일
```

## 사용 기술

- HTML (35%)
- CSS (65%)
